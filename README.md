# CDR Микросервис

## Описание проекта

Этот проект представляет собой микросервис, разработанный на Spring Boot, который эмулирует работу коммутатора сотового оператора. Он генерирует записи CDR (Call Detail Records), сохраняет их в базу данных H2 и предоставляет REST API для получения отчетов UDR (Usage Data Reports) и генерации сводных отчетов по CDR записям для абонентов.

### Основные функции
- Генерация CDR записей за год в хронологическом порядке.
- Сохранение CDR записей в базу данных H2.
- REST API для получения UDR отчетов по одному абоненту (за месяц или весь период) и по всем абонентам за месяц.
- Генерация CDR отчетов в формате CSV для указанного абонента и периода.

## Требования
- **Java 17**
- **Gradle**
- **H2 Database**

## Запуск приложения
   ```bash
   java -jar cdr-microservice-0.0.1-SNAPSHOT.jar
   ```

Приложение будет доступно на порту `8081`.

## REST API

### Получение UDR отчета по одному абоненту
- **URL:** `/api/udr/{msisdn}`
- **Метод:** GET
- **Параметры:**
    - `msisdn` (path): номер абонента (например, `79990000001`)
    - `yearMonth` (query, необязательный): месяц в формате `YYYY-MM` (например, `2024-01`)
- **Пример запроса:**
  ```bash
  curl -X GET "http://localhost:8081/api/udr/79990000001?yearMonth=2024-01"
  ```
- **Пример ответа:**
  ```json
  {
      "msisdn": "79990000001",
      "incomingCall": "30:32:06",
      "outcomingCall": "33:01:26"
  }
  ```

### Получение UDR отчетов по всем абонентам за месяц
- **URL:** `/api/udr`
- **Метод:** GET
- **Параметры:**
    - `yearMonth` (query): месяц в формате `YYYY-MM` (например, `2024-01`)
- **Пример запроса:**
  ```bash
  curl -X GET "http://localhost:8081/api/udr?yearMonth=2024-01"
  ```
- **Пример ответа:**
  ```json
  [
      {
          "msisdn": "79990000001",
          "incomingCall": "30:32:06",
          "outcomingCall": "33:01:26"
      },
      {
          "msisdn": "79990000002",
          "incomingCall": "37:22:27",
          "outcomingCall": "36:46:40"
      }
  ]
  ```

### Генерация CDR отчета
- **URL:** `/api/cdr-report`
- **Метод:** POST
- **Тело запроса:** JSON с полями `msisdn`, `startDate`, `endDate`
- **Результат:** Файл отчета сохраняется в директории `reports/` с именем вида `79990000001_61f0c404-5cb3-11e7-907b-a6006ad3dba0.csv`.

## Структура проекта
- **`CdrMicroserviceApplication.java`**: точка входа в приложение.
- **`controller/`**: REST-контроллеры (`UDRController`, `CDRReportController`).
- **`service/`**: бизнес-логика (`UDRService`, `CDRReportService`, `DataGeneratorService`).
- **`repository/`**: доступ к базе данных (`CDRRecordRepository`, `SubscriberRepository`).
- **`model/`**: сущности (`CDRRecord`, `Subscriber`).
- **`DTO/`**: объекты передачи данных (`UDRDto`, `CDRReportRequest`).
- **`DataInitializer.java`**: генерация тестовых данных при запуске.

## База данных
Используется H2 Database. Данные генерируются автоматически при запуске приложения (если профиль не `test`).

Код покрыт тестами более чем на 75%, что обеспечивает надежность и стабильность приложения.
